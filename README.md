# setup-starship-zoxide

A setup script that installs Starship and zoxide, configures the Starship Pure
prompt preset, and adds both tools to your Bash startup configuration.

## Install

Run this on an Ubuntu or Debian-based system with Bash and `sudo` access:

```bash
curl -fsSL https://raw.githubusercontent.com/shanujha/setup-starship-zoxide.sh/main/setup.sh | bash
```

The script updates and upgrades installed packages, installs its dependencies,
and adds initialization commands to `~/.bashrc`. Open a new terminal after it
finishes if the prompt does not update immediately.

To review the script before running it:

```bash
curl -fsSL https://raw.githubusercontent.com/shanujha/setup-starship-zoxide.sh/main/setup.sh
```
